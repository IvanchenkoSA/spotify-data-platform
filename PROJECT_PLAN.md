# План развития проекта

Этот файл — актуальная точка продолжения работы. Перед началом новой задачи сначала сверяй статус здесь, а после завершения задачи обновляй его вместе с кодом и документацией.

## Текущая точка

Дата обновления: 2026-07-31

Готово:

- Локальная загрузка истории недавно прослушанных треков из Spotify с OAuth и watermark.
- PostgreSQL: raw-слой, `mart_listening_history` и аналитические SQL-вьюхи.
- Streamlit-дашборд: активность по дням и часам, топ треков, топ артистов и последние прослушивания.
- Обогащение артистов жанровыми тегами Last.fm.
- Жанровая аналитика: `dim_artists`, `artist_genres`, `analytics_top_genres` и график `Top genres`.

Проверенные данные на момент обновления:

- 186 прослушиваний в raw- и mart-слоях.
- 65 артистов обработано Last.fm; у 61 есть жанровые теги.
- 293 жанровых тега Last.fm.

## Правило ведения плана и Git

При каждом завершённом изменении:

1. Обновить этот файл: отметить выполненное, добавить следующий конкретный шаг и при необходимости обновить текущие цифры.
2. Проверить изменение в объёме, соответствующем риску.
3. Создать коммит, включающий код, документацию и `PROJECT_PLAN.md`.
4. Отправить коммит в `origin/master` на GitHub.

Не хранить в GitHub `.env`, `.spotify-token.json` или выгруженные персональные данные из `data/raw/`.
